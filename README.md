# Advanced Features Implementation – PHP & MySQL

## 📌 Project Overview

This project is a PHP and MySQL web application enhanced with advanced features such as **Search Functionality, Pagination, and User Interface Improvements**. The main objective is to make the application more user-friendly, efficient, and easy to navigate.

## 🎯 Objectives

* Enhance the application with advanced features.
* Allow users to search posts by title or content.
* Implement pagination for better content navigation.
* Improve the overall user interface and user experience.

## 🚀 Features

### 🔍 Search Functionality

* Search posts using keywords.
* Search based on post title or content.
* Display relevant search results dynamically.

### 📄 Pagination

* Display a limited number of posts per page.
* Provide navigation links to move between pages.
* Improve performance and readability when handling multiple posts.

### 🎨 User Interface Improvements

* Improved application design using CSS.
* Enhanced user experience with a clean layout.
* Responsive design for better usability.

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS
* **Backend:** PHP
* **Database:** MySQL
* **Server:** XAMPP / Apache

## 📂 Project Structure

```text
project-folder/
│
├── index.php
├── search.php
├── config.php
├── style.css
├── database.sql
└── README.md
```

## ⚙️ How to Run the Project

1. Install **XAMPP** or any PHP local server.
2. Place the project folder inside the `htdocs` directory.
3. Start **Apache** and **MySQL** from XAMPP.
4. Create the required database in MySQL.
5. Import the `database.sql` file.
6. Update the database configuration in `config.php`.
7. Open your browser and run:

```text
http://localhost/project-folder/
```
